# Security

We recommend using the latest released version.

## Scope

This policy covers the code in this repo: the `fce` CLI and the checks it runs.
The library, the launcher, the image recipe and the contracts that extensions build on are the [extension scaffold](https://github.com/flare-foundation/fce-go-scaffold)'s; report a vulnerability in them as its policy describes.

## Reporting Vulnerabilities

Please do not report a vulnerability using an issue or any other public channel.

If you have found a possible vulnerability, please send an email to `security at flare dot network`.

## Vulnerability disclosures

Critical vulnerabilities will be disclosed via GitHub's [security advisory](https://github.com/flare-foundation/fce-tooling/security) system.

## Audit reports

Audit reports are published on Flare's [Developer Hub](https://dev.flare.network/support/audits).
